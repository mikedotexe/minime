# Shared study inquiries — September 9, 2026

Mike authorized named question threads, relationship navigation, bounded study
sessions and execution traces with parity across Minime and Astrid, and a live
rollout. The common Rust reader owns the policy; this adapter passes only Minime's
host-configured workspace and identity, preserves complete input across all three
provider paths, and records one journal entry for the resulting session.

Commands: SELF_STUDY QUESTION NEW <question>, QUESTION qN, QUESTION HOME,
QUESTION PARK qN, QUESTION RESOLVE qN [finding]; RELATE <exact symbol>;
SESSION OPEN repository/path line | OPEN repository/path line (optional third
OPEN); TRACE LAST or TRACE <own exact job_id/action_id>. Use SELF_STUDY as the
prefix and the ordinary NEXT for question mutations. All navigation follows the
same shared catalog, exact source identities and verified delivery checkpoints.

Inquiry status is authored, never a comprehension score. Lexical relationship
hits are candidates, not proof of calls. Sessions deliver 2–3 smaller pages within
one bounded input and advance all selected bookmarks only after verified complete
generation; one session is one study, with per-page receipts. TRACE distinguishes
source delivery, a response's requested NEXT and separately recorded execution.
Absent records remain unknown. Private source exclusions remain; runtime trace
access is restricted to the host's own retained jobs/actions.

The existing 4,096-token source-study ceiling remains, with no required length.
Checkpoint schema 2 reads old state without resetting progress or notes; old
executables reject schema 2 to avoid dropping inquiries. Rollback must preserve
new state or deliberately reconcile a retained prior checkpoint. Astrid's owning
release retains copied-state migration evidence, parity tests and activation
proof. Natural usefulness remains a research question.
